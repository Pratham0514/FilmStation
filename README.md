# 🍿 FILMS_STATION 🎥

A full-stack movie management web application where users can browse, search, and manage movies. Built using React, Node.js, Express, and MongoDB.

---

## 🚀 Features

- 🎥 View all movies  
- 🔍 Search movies by title  
- ➕ Add new movies  
- ✏️ Edit movie details  
- ❌ Delete movies  
- ⚡ Fast API integration  
- 🔔 Toast notifications  

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios
- React Router
- React Hot Toast

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- dotenv
